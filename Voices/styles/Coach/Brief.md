# Coach

One note, one image, one next action. A coaching note names a single thing to
change and makes tonight's practice obvious.

- **Note** — 100 words, no more. One note means one correction, and a
  second correction is a second note.
- **Image** — exactly one image. The note shows the thing it names; zero
  images is telling, two is a slideshow.
- **NextAction** — exactly one line beginning "Next: ". The note ends in
  motion -- a single concrete step, not a menu.
